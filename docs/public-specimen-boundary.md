# Public specimen boundary

The initial Free Graph specimens were created from conversation and lyric-corpus material whose source records explicitly marked some content as `private` with `export: pointer-only`.

Those private excerpts do not belong in this public repository.

The public specimens therefore preserve:

- content digests;
- source coordinates at the lawful resolution;
- node and relation structure;
- uncertainty and non-imports;
- an explicit redaction notice.

They do **not** publish the private excerpts.

This boundary is not cosmetic. A provenance system that requires leaking the source in order to prove the source existed is defective.
